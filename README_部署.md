# 群星云Hub 项目文件管理系统 · 宝塔面板部署说明

面向新手，全程图形化操作，不用敲命令。服务器环境：宝塔面板 13.0.0 + PHP 8.0 + MySQL 5.6。

项目组织：群星云

项目开发者：小伍

多数用AI编写，有问题可以访问cloud.quntec.cn注册账户提交技术工单即可

***

## 一、准备：安装软件环境

在宝塔「软件商店」里安装：

- **Nginx**（任意 1.20+ 版本即可，宝塔默认就有）

- **PHP 8.0**

- **MySQL 5.6**（软件商店里搜 MySQL，选 5.6 安装）

> 如果宝塔提示 PHP 8.0 没装，在「软件商店 → PHP」里安装 8.0 版本。

***

## 二、建网站

1. 宝塔左侧「网站 → 添加站点」。
2. 域名：填你的域名（没域名可填服务器 IP）。
3. 根目录：默认 `/www/wwwroot/你的域名`，先保持。
4. PHP 版本：选 **PHP 8.0**。
5. 数据库：这里**先不建**（待会单独建，方便你记住账号密码）。创建后点提交。

***

## 三、上传源码

1. 把 `quntechub.zip` 上传到网站根目录（宝塔「文件」进入 `/www/wwwroot/你的域名`，上传）。
2. 右键解压到当前目录。解压后根目录应能看到 `public`、`app`、`config`、`install.sql` 等文件夹。
3. 把解压出来的所有文件保持在网站根目录下（即 `public` 文件夹就在根目录里）。

***

## 四、设置运行目录（重要）

1. 网站 → 你的站点 → 设置 → 「网站目录」。
2. **运行目录** 改为 `/public`，保存。

   - 这样 `config`、`app` 等敏感目录就不会被外部直接访问，更安全。

***

## 五、设置伪静态（Nginx）

网站 → 你的站点 → 设置 → 「伪静态」，把下面内容粘进去，保存：

```nginx
location / {
    try_files $uri $uri/ /index.php?$query_string;
}

# 禁止 uploads 目录里的脚本被执行
location ~* ^/uploads/.*\.(php|phtml|phar|pht|php3|php4|php5|php7)$ {
    deny all;
}
```

> 如果你用的是 Apache，则无需此项，根目录自带的 `.htaccess` 已生效。

***

## 六、建数据库

1. 宝塔「数据库 → 添加数据库」。
2. 数据库名：随便，例如 `quntechub`。
3. 用户名、密码：**记下来**（安装时要填）。
4. 访问权限：本地即可。
5. 提交。数据库会被自动建好（安装向导也会兜底尝试创建）。

***

## 七、给目录权限

宝塔「文件」进入网站根目录：

1. 右键 `config` 文件夹 → 权限 → 设为 `755`，所有者选 `www`。
2. 右键 `public/uploads` 文件夹 → 权限 → 设为 `755`，所有者选 `www`（上传文件需要可写）。

> 不确定就两个目录都设 `755`、所有者 `www`。

***

## 八、调大上传限制（视频/大文件才用得上）

宝塔「软件商店 → PHP 8.0 → 设置 → 配置修改」：

- `upload_max_filesize` 改为 `512M`（或更大）

- `post_max_size` 改为 `512M`

- `max_execution_time` 改为 `300`
  保存后重启 PHP。

***

## 九、运行安装向导

1. 浏览器打开 `http://你的域名/`，会自动跳到安装页。
2. 填入第六步的：数据库地址（一般 `localhost`）、端口 `3306`、数据库名、用户名、密码。
3. 设置管理员用户名和密码（密码至少 6 位）。
4. 点「开始安装」。系统自动建表、写配置。
5. 完成 → 跳到登录页，用管理员账号登录即可使用。

***

## 常见问题

**Q：打开域名显示 500 / 空白？**
A：检查 PHP 版本是否 8.0、运行目录是否 `/public`、伪静态是否粘贴。

**Q：安装页提示 config 写入失败？**
A：把 `config` 目录权限设为 `755`、所有者 `www`。

**Q：上传大文件失败？**
A：按第八步调大 PHP 上传限制。

**Q：想换数据库？**
A：删除 `config/config.php`，重新访问域名即可重新安装。

**Q：忘记管理员密码？**
A：宝塔 phpMyAdmin 打开 `quntechub` 库，在 `admin` 表里把 `password_hash` 改为新密码的 bcrypt 值；或删掉 `config/config.php` 重新安装（会重置账号）。
